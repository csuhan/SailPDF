Sail PDF 隐私说明
生效日期：2026-10-30
项目与联系入口：https://github.com/csuhan/SailPDF

1. 本机文档处理
阅读、搜索、编辑、批注、页面处理和 macOS 文字识别默认在设备上完成。Sail PDF 不设置账号，不内置广告追踪或自动文档上传，也不默认发送使用统计、崩溃报告或诊断文件。

2. AI 的处理方式
选择内置本机模型后，问答和文档检索在本机运行。下载模型时会连接 Hugging Face，其服务器及下载基础设施会收到正常下载所需的网络信息，例如 IP 地址；模型下载不包含 PDF 内容。
选择自定义 AI 接口后，问题、对话上下文，以及检索、摘要或修改任务需要的文档内容会发送到你配置的接口。处理范围取决于操作，不承诺所有任务只发送短小片段。局域网接口也会把数据传出当前设备。请先确认服务商的数据保留政策及你对文档的处理权限。
外部服务有自己的条款与隐私政策，Sail PDF 不控制其后续处理。

3. 本地保存的数据
设置、阅读位置、最近文件、书签、收藏与恢复草稿保存在本机。最近列表可能包含文件路径；草稿可含文字、批注、图片及表单值，应按原文档的敏感程度保护。手写签名由你选择保存并可在签名界面删除。
桌面版 API Key 通过 Electron safeStorage 使用操作系统的安全机制加密后存放，不写入普通设置；macOS 使用系统钥匙串保护加密密钥。系统安全存储不可用时仅在内存中使用。网页版 API Key 仅保留在当前会话内，刷新后需重新输入。
旧版本普通设置中的 API Key 会在启动时迁移，并从当前设置中移除；系统备份、文件系统历史副本或浏览器存储的历史页可能仍保留旧数据，迁移不等同安全擦除所有历史副本。
本机模型文件与其运行日志位于应用数据目录；日志用于排查模型启动/运行故障，不作为自动发送的遥测。

4. 你的控制
可在设置中关闭恢复草稿、查看和删除草稿；在最近列表中移除记录；在 AI 设置中断开接口或删除本机模型。断开接口会清除应用保存的 API Key。删除草稿不修改 PDF 原文件；导出和保存由你选择目标。
卸载应用可能不会自动删除应用数据或系统备份。需要清理全部数据时，请先备份必要文件、在设置中清除草稿和凭据，再清理操作系统中的应用数据目录。

5. 反馈与外部链接
反馈入口打开 GitHub 页面，由你决定提交哪些信息；GitHub Issues 通常公开可见。诊断导出是本机操作，默认只含版本、平台和功能状态，不包含文档内容、文件路径、文件名、API Key、对话或运行日志。分享前仍应自行核对。
点击网页、下载或反馈链接后，相应网站会依据其政策处理正常的访问数据。本应用不会自动提交反馈内容或上传 PDF。

6. 说明更新与联系
变更随版本发布在仓库中。隐私问题可通过项目反馈入口联系维护者；请勿公开上传合同、身份证件、密钥或其他敏感内容。
