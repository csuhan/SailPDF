# Security policy

Please report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/csuhan/SailPDF/security/advisories/new). Avoid disclosing exploitable details in public issues before the maintainer has reviewed the report.

Include the affected version, platform, impact and a minimal synthetic reproduction. Do not include API keys, private PDFs, full local profiles or personal data. If the private reporting page is unavailable, open a public issue asking for a private contact method without describing the vulnerability.

The project is in beta. Security fixes target the current release; older local development builds are not maintained release branches. Review the [privacy notice](public/legal/PRIVACY.en.txt) and keep independent backups of important documents.
